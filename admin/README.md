# Sales Engine Admin Dashboard

Platform admin UI for Sales Engine. This app lives at `admin/` in the Sales Engine repository, with the Next.js codebase at this folder’s root.

## Run locally

```bash
cd admin
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001).

## Also in this folder

- `PRODUCT.md` and `DESIGN.md` — product and design notes from the original admin repository
- `.impeccable/` — design/review artifacts from the original repository
